# Krypto Pengus

3,333 pixelated penguins waddling toward greatness on Sui Network.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide Icons

## Deploy

Deploy on [Vercel](https://vercel.com) — connect the repo and it just works.
